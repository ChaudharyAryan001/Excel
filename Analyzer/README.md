
# 📊 Data Analysis & Data Intelligence Dashboard Projects

## 📌 Project Overview

This repository contains two Microsoft Excel projects developed to demonstrate practical skills in Data Analysis, Data Cleaning, Data Visualization, Business Intelligence, and Dashboard Development.

The projects use Excel formulas, analytical techniques, charts, and interactive dashboards to convert raw data into meaningful business insights.

---

## 📁 Projects Included

### 1. Sales Data Analyzer

**File:** `Analyzer.xlsx`

A sales data analysis project designed to evaluate business performance, customer behavior, regional sales, and profitability.

**Key Features:**
- Raw sales data analysis
- Customer-wise sales analysis
- Top 10 customer identification
- Region-wise sales performance
- Monthly sales trend analysis
- Descriptive statistical analysis
- Discount vs. Profit regression analysis
- Professional Sales Performance Dashboard

**Excel Functions Used:**
- SUM and SUMIF
- COUNT and COUNTA
- AVERAGE
- MAX and MIN
- INDEX and MATCH
- XLOOKUP
- LARGE
- CORREL
- STDEV.S
- IF and IFERROR
- TEXT

---

### 2. Data Intelligence Dashboard

**File:** `Data_Intelligence_Dashboard_.xlsx`

An interactive Excel dashboard project that analyzes customer transactions and presents business performance through dynamic KPIs, charts, and automated reports.

**Key Features:**
- Customer transaction analysis
- Interactive dashboard
- Revenue and order analysis
- Region-wise performance
- Category-wise sales analysis
- Payment method analysis
- Customer segmentation
- Dynamic KPI cards
- Automated business insights report
- Interactive dropdown filters
- Data visualization and trend analysis

**Excel Concepts Used:**
- TODAY and NOW
- DATEDIF and EOMONTH
- FILTER
- SUMIFS and COUNTIFS
- IF and IFERROR
- Conditional Formatting
- Data Validation
- Dynamic formulas
- Dashboard automation
- Pivot Tables and Pivot Charts
- Slicers and Timelines
- Scenario Manager
- Goal Seek

## 🚀 How to Use

1. Download or clone this repository.
2. Open the Excel workbook using Microsoft Excel.
3. Navigate through the different worksheets.
4. Explore the analysis, formulas, and dashboards.
5. Use available dropdown filters to interact with the dashboard.

**Note:** Microsoft Excel 365 or a recent Excel version is recommended for compatibility with modern functions such as XLOOKUP and FILTER.
